## Beangle SQLPlus

Beangle SQLPlus 是一个面向关系数据库的工具集，提供数据库迁移、报告生成、SQL 检查等功能。

### 核心功能

| 模块 | 描述 |
|------|------|
| **Transport** | 数据库迁移工具，支持跨数据库数据迁移 |
| **Report** | 数据库报告生成器，生成数据库文档 |
| **Lint** | SQL 检查工具，检测数据库设计问题 |
| **Shell** | 命令行工具，提供交互式数据库操作 |

### 支持的数据库

- **Oracle**：完整支持
- **MySQL**：完整支持
- **PostgreSQL**：完整支持
- **SQL Server**：完整支持
- **SQLite**：基础支持

### Transport 数据迁移

#### 功能特点

- **跨数据库迁移**：支持不同数据库之间的数据迁移
- **增量迁移**：支持增量数据同步
- **数据转换**：支持字段类型转换
- **批量处理**：高效的批量数据处理

#### 迁移流程

```
源数据库
    ↓
读取数据
    ↓
数据转换
    ↓
写入目标数据库
    ↓
验证数据
```

### Report 报告生成

#### 生成内容

| 报告类型 | 描述 |
|----------|------|
| **Schema 报告** | 数据库表结构文档 |
| **数据字典** | 完整的数据字典文档 |
| **依赖分析** | 表之间的依赖关系图 |
| **变更报告** | 数据库变更历史 |

### Lint SQL 检查

#### 检查规则

| 规则 | 描述 |
|------|------|
| **序列检查** | 检查表序列命名规范 |
| **约束检查** | 检查外键约束完整性 |
| **索引检查** | 检查索引使用情况 |
| **临时表检查** | 检测临时表使用 |

### Shell 命令行工具

#### 主要命令

| 命令 | 描述 |
|------|------|
| `export` | 导出数据库结构和数据 |
| `import` | 导入数据库结构和数据 |
| `diff` | 比较两个数据库差异 |
| `lint` | 检查数据库设计问题 |
| `report` | 生成数据库报告 |

### 依赖关系

- **Commons**：核心工具库
- **JDBC**：数据库访问
- **Doc**：文档生成支持

### 典型使用场景

1. **数据库迁移**：将数据从开发环境迁移到生产环境
2. **数据库文档**：自动生成数据库设计文档
3. **数据库审计**：检查数据库设计规范
4. **数据同步**：跨数据库的数据同步
